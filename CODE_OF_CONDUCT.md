# Code of Conduct

We want this project to be a welcoming and constructive open-source project.

## Expected behavior

- Be respectful and professional.
- Assume good intent and discuss technical disagreements constructively.
- Focus feedback on the code, documentation, or proposal rather than on individuals.
- Do not share private conversations, credentials, or other sensitive information in issues or pull requests.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, deliberate disruption, or publishing someone else's private information are not acceptable.

Project maintainers may remove content or contributions that violate this code of conduct.

## Reporting

If you encounter unacceptable behavior, open a private report through GitHub's repository security/reporting features where available, or contact the project maintainers through the repository's published contact method.
